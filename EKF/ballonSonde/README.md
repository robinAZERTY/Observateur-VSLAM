### Énoncé
Le ballon sonde que vous venez d'envoyer dans l'atmosphère est équipé d'une balise GPS et d'un capteur de température. Malheureusement, le GPS ne fonctionne plus. On souhaite donc estimer l'altitude sachant la température.
